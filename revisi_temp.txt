BAB II: TINJAUAN PUSTAKA
2.x. Formalisasi Matematis Fungsi Keanggotaan Fuzzy Mamdani
Proses fuzzifikasi memerlukan fungsi matematis kontinuitas untuk memetakan nilai tegas (crisp) menjadi derajat keanggotaan fuzzy dengan rentang μ(x) ∈ [0, 1]. Pada sistem ini, representasi himpunan fuzzy menggunakan tiga jenis kurva utama, yaitu Kurva Linier Turun (Linear Down), Kurva Segitiga (Triangular), dan Kurva Linier Naik (Linear Up).
1. Fungsi Kurva Linier Turun
Kurva linier turun digunakan untuk memetakan parameter himpunan awal (seperti Rendah, Baru, atau Lambat) yang memiliki nilai optimal penuh pada batas bawah dan menurun secara konstan hingga nol pada batas atas. Persamaan matematisnya dirumuskan sebagai berikut:
μ_down(x) =   1,               jika x ≤ a  (b - x)/(b - a), jika a < x < b  0,               jika x ≥ b
2. Fungsi Kurva Linier Naik
Kurva linier naik digunakan untuk memetakan parameter himpunan akhir (seperti Tinggi, Lama, atau Cepat) di mana nilai derajat keanggotaan bernilai nol pada batas bawah dan merangkak naik secara linier menuju nilai optimal satu pada batas atas. Persamaan matematisnya dirumuskan sebagai berikut:
μ_up(x) =   0,               jika x ≤ a  (x - a)/(b - a), jika a < x < b  1,               jika x ≥ b
3. Fungsi Kurva Segitiga (Triangular)
Kurva segitiga memetakan parameter transisi atau kondisi Menengah/Sedang. Kurva ini dibentuk oleh tiga parameter batas utama (a, b, c) di mana nilai derajat keanggotaan mencapai puncak (μ=1) tepat pada titik b. Persamaan matematisnya dirumuskan sebagai berikut:
μ_tri(x) =   0,               jika x ≤ a atau x ≥ c  (x - a)/(b - a), jika a < x ≤ b  (c - x)/(c - b), jika b < x < c
4. Metode Defuzzifikasi Centroid (Center of Area)
Tahap akhir untuk menghasilkan output nilai tegas (crisp score) dari komposisi aturan fuzzy dilakukan dengan metode Centroid diskrit, yang diimplementasikan melalui formula penjumlahan sampel terintegrasi sebagai berikut:
Z* = ∑(z_i * μ_output(z_i)) / ∑(μ_output(z_i))
Keterangan: Z* merupakan persentase keausan akhir, z_i adalah nilai sampel domain output, dan μ_output(z_i) merupakan nilai derajat keanggotaan hasil agregasi aturan fuzzy.
